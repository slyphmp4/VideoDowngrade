# Degrader visual direction

## Core idea

A dark video laboratory rather than a generic converter. The interface should feel like a small professional signal-processing tool: quiet, technical and deliberate.

## Current tokens

- background: `#090A0D`
- surfaces: `#111318` / `#15181F`
- main text: `#F7F8FA`
- secondary text: `#858B98`
- borders: translucent white
- action accent: `#D9FF43`
- radius: 10–18 px

## Rules

1. White is for information, acid accent is only for state/action.
2. Avoid large gradients, glassmorphism overload and generic SaaS cards.
3. Controls should resemble signal controls, not form fields.
4. Motion should explain state changes: upload → probe → process → result.
5. Keep the preview visually dominant.
6. Presets describe a visual character, not only technical numbers.

## Planned style evolution

- waveform / histogram micro-visuals
- real before/after frame scrubber
- animated degradation preview
- custom icon / wordmark
- richer job state animations
- optional monochrome theme with no accent color
